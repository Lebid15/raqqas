# الخلفية — سوق الرقة

Django 5 + Django REST Framework · PostgreSQL في الإنتاج · SQLite في التطوير.

## التشغيل خلال دقيقتين

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate            # ويندوز   ·   source .venv/bin/activate على لينكس
pip install -r requirements.txt
copy .env.example .env            # cp على لينكس
python manage.py migrate
python manage.py seed --demo      # أقسام وأحياء + بيانات تجريبية
python manage.py runserver
```

- الواجهة: http://127.0.0.1:8000/api/v1/
- التوثيق التفاعلي: http://127.0.0.1:8000/api/docs/
- لوحة Django (شبكة أمان لا أكثر): http://127.0.0.1:8000/django-admin/

`seed --demo` ينشئ مدير تجربة: **0900000000 / admin1234** — غيّره فورًا.
للإنتاج: `python manage.py createsuperuser`.

## قواعد ثابتة في هذا المشروع

**1. لا شرطة مائلة في نهاية المسار.** `/api/v1/listings` وليس `/listings/`.
إعادة التوجيه 301 تُسقط جسم الطلب وترويسة المصادقة في بعض عملاء أندرويد.

**2. القراءة للزائر · الكتابة للمسجَّل** (القرار 17 في `plan2.md`).

| مفتوح للزائر | يحتاج تسجيلًا |
|---|---|
| `app-config` · `home` · `categories` · `cities` | نشر وتعديل وحذف إعلان |
| `listings` (قائمة · تفاصيل · بحث · مرشّحات) | المفضلة على الخادم |
| `theme-presets` · `report-reasons` | **`listings/{id}/contact` — كشف رقم البائع** |
| `downloads/track` · `health` | البلاغ عن إعلان · الإشعارات |

**3. رقم البائع لا يظهر في أي رد عام — أبدًا.**
`PublicSellerSerializer` لا يحتوي حقل هاتف أصلًا. النقطة الوحيدة التي تكشفه هي
`GET /listings/{id}/contact`، وهي محميّة بتسجيل الدخول ومحدودة بـ 60 طلبًا/ساعة.
هذا ينفّذ القرار 17 ويحمي الأرقام من السحب الآلي في آن واحد.

**4. كل ما يريد الأدمن تغييره يمرّ من `AppConfig`** (`plan2` §4.2) — ولا يُكتب
في الكود: الألوان والخط والاستدارة والعملة ونصوص الصفحة التعريفية وحدود النشر
وتشغيل/إيقاف المزايا.

**5. الأسعار أرقام فقط.** لا حقل عملة في `listings`. الرمز من `AppConfig`،
والرقم لا يتغيّر إطلاقًا (`plan2` §6). تبديل العملة يعيد `currency_warning`.

**6. كل ما يكتبه الأدمن بثلاث لغات** (`name_ar` · `name_tr` · `name_en`)،
وما يكتبه المستخدم يبقى كما هو بلا ترجمة.

## نقاط مهمّة في الواجهة

### `GET /api/v1/app-config`
يطلبها التطبيق عند كل إقلاع. تدعم `ETag` — إن لم تتغيّر النسخة يعود **304**
بلا جسم، وهو توفير حقيقي على إنترنت ضعيف. التطبيق يخزّنها محليًا ويعمل بها
بلا اتصال.

### `GET /api/v1/home`
رد واحد يكفي الشاشة الأولى (أقسام + مميّزة + أحدث) بدل ثلاثة طلبات.

### `POST /api/v1/favorites/merge`
الزائر يحفظ المفضلة محليًا في التطبيق. عند أول تسجيل دخول يرسل التطبيق القائمة
هنا فتُنقل إلى حسابه. بلا هذا يفقد الناس ما جمعوه قبل التسجيل.

### `GET /api/v1/admin/review-queue`
صفّ المراجعة مرتّبًا **بالأقدم أولًا**، ومعه `waiting`: عدد المنتظرين وأطول
انتظار ومتوسط آخر سبعة أيام. إن تجاوز المتوسط ساعتين يظهر `over_threshold: true`
— وهي إشارة الانتقال إلى نمط «الأعضاء الجدد فقط» بتغيير `review_mode` وحده
(`plan2` §8.6).

## معالجة الصور

الخادم يعيد ترميز كل صورة مرفوعة ولا يثق بضغط العميل:

- أطول ضلع 1600 بكسل للصورة، و480 للمصغّرة، بجودة 82 ⇐ حجم مضمون.
- تصحيح دوران صور الجوال (EXIF).
- **حذف بيانات EXIF** — وفيها غالبًا الموقع الجغرافي لمن التقط الصورة.

## نشر الإنتاج (ملخّص)

1. `DATABASE_URL` لـ PostgreSQL · `DEBUG=False` · `SECRET_KEY` عشوائي طويل.
2. `python manage.py migrate && python manage.py collectstatic --noinput`
3. `gunicorn souq.wsgi:application` خلف Nginx (يخدم `/media/` و`/static/`).
4. نسخ احتياطي يومي لقاعدة البيانات **خارج الخادم** (`plan2` §7.3).
5. ⚠️ لا تضع Cloudflare أمام الخادم قبل اختبار الوصول من داخل سوريا
   (`plan2` §7.3 — قد يضيف تحدّي CAPTCHA للزوّار السوريين).
