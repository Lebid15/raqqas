# التطبيق — سوق الرقة

React Native + Expo (TypeScript) · أندرويد · ويب · وiOS جاهز لاحقًا.

## كيف أراه الآن؟

**١. شغّل المحرّك (الخلفية) في نافذة:**

```bash
cd backend
.venv\Scripts\python.exe manage.py runserver
```

**٢. شغّل التطبيق في نافذة ثانية:**

```bash
cd app
npm run web          # يفتح في المتصفّح: http://localhost:8081
```

### على جوالك الحقيقي (بلا APK)

1. ثبّت تطبيق **Expo Go** من متجر جوجل.
2. اعرف رقم IP جهازك على الشبكة: `ipconfig` → مثلًا `192.168.1.5`.
3. شغّل الخلفية على الشبكة كلّها لا على جهازك فقط:
   ```bash
   .venv\Scripts\python.exe manage.py runserver 0.0.0.0:8000
   ```
4. شغّل التطبيق مع عنوان الخلفية:
   ```bash
   cd app
   set EXPO_PUBLIC_API_URL=http://192.168.1.5:8000/api/v1
   npx expo start
   ```
5. امسح رمز QR بتطبيق Expo Go — يظهر التطبيق على جوالك فورًا.

> الجوال والحاسوب يجب أن يكونا على **نفس شبكة الواي فاي**.

## إنتاج ملف APK

```bash
npm install -g eas-cli
eas login
eas build -p android --profile production
```

قبل البناء: ضع عنوان الخادم الحقيقي في `EXPO_PUBLIC_API_URL` أو في
`app.json → extra.apiUrl`.

> ⚠️ **مفتاح التوقيع (Keystore) مسؤوليتنا** (plan2 §7.2). إن ضاع، **لا يمكن
> تحديث التطبيق لأي مستخدم إطلاقًا** — لا حلّ إلا نشر تطبيق جديد وخسارة كل من
> ثبّت القديم. نسخة احتياطية في مكانين منفصلين، وكلمة السرّ بعيدًا عن المستودع.

app/

    ├── i18n/               ar · tr · en + الاتجاه
    ├── state/              AppConfig · Auth · Favorites
    ├── components/         الترويسة · الشريط السفلي · البطاقات · النوافذ · الحقول

## قواعد ثابتة

**١. لا لون ولا قياس مكتوب في شاشة.** كل شيء من `useTheme()`، وقيمه تأتي من
`app-config` — أي أن الأدمن يغيّر شكل التطبيق كله من اللوحة بلا إصدار جديد
(plan2 §4). ملف `src/theme/tokens.ts` هو شبكة الأمان حين لا يوجد إنترنت.

**٢. لا نصّ مكتوب في شاشة.** كل نصّ مفتاح في `src/i18n/` بثلاث لغات
(plan2 §5). والتخطيط منطقي (`t.row` · `t.textStart`) فينقلب مع اللغة بلا كود
منفصل للعربية.

**٣. الزائر يتصفّح كل شيء** (قرار 17). ما يحتاج تسجيلًا يمرّ من
`requireAuth(reason, action)`:

```ts
requireAuth('contact', async () => {
  const contact = await api.get(`/listings/${id}/contact`);
  Linking.openURL(contact.whatsapp_url);
});
```

إن كان مسجَّلًا نُفِّذ فورًا، وإلا فُتحت شاشة الدخول — وبعد نجاحها **يُستأنف
الإجراء نفسه تلقائيًا**. أي أن من ضغط «تواصل عبر واتساب» يجد واتساب مفتوحًا بعد
الدخول، ولا يُرمى في الصفحة الرئيسية.

**٤. الشاشة تعرض المحفوظ أولًا ثم تحدّث.** `useResource` يقرأ من الذاكرة
المحلّية قبل الشبكة. على إنترنت الرقة هذا هو الفرق بين شاشة تدور وشاشة فيها
محتوى (plan2 §7.3).

**٥. رقم البائع لا يصل التطبيق أصلًا** إلا من نقطة `contact` المحميّة. لا يوجد
حقل هاتف في بيانات الإعلان العامة، فلا مجال لتسريبه بالخطأ.

## أشياء قد تفاجئك

- **الخطوط محزومة** (Cairo) ولا تُنزَّل من الإنترنت (plan2 §7). ومع ذلك يوجد
  مهلة 2.5 ثانية: إن تأخّر تحميلها يُقلع التطبيق بخط النظام بدل شاشة خضراء
  لا تنتهي.
- **لا نستخدم `I18nManager.forceRTL`** رغم أنه الطريقة المعتادة — لأنه يفرض
  إعادة تشغيل التطبيق عند تغيير اللغة، والمستخدم لا يتوقّع أن ينغلق التطبيق في
  وجهه. الاتجاه يأتي من الأنماط بدلًا منه.
- **محاكي أندرويد لا يرى `localhost`** — العنوان `10.0.2.2` هو جهازك من داخله.
- **زر «أضف إعلان» ليس تبويبًا**: الضغطة تُعترَض في `RootNavigator` وتفتح شاشة
  فوق كل شيء بعد التحقّق من التسجيل.
