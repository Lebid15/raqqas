## 🎨 نموذج التصميم

نموذج أوّلي كامل بـ HTML/CSS/JS خالص — **بدون أي مكتبة خارجية**.

**ابدأ من هنا:** [`design/screens.html`](design/screens.html) — فهرس كل الشاشات + الهوية البصرية.

### التشغيل محليًا

افتح `design/screens.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا لتجربته على الجوال:

```bash
cd design
python -m http.server 8080
# ثم افتح من الجوال: http://<عنوان-جهازك>:8080/screens.html
```

## ✅ قرارات معتمدة

- **التحقق من الهاتف:** واتساب OTP — **مؤجّل حاليًا**، والبديل تفعيل يدوي عبر طبقة `VerificationProvider` مجرّدة.
- **الدفع:** خارج المنصّة مع **تحقق يدوي** من لوحة الإدارة (لا بوابات دفع إلكترونية — غير متاحة في سوريا).
- **نظام التقييم ⭐:** يُضاف بعد الإطلاق، وليس في النسخة الأولى.
- **النسخة الأولى مجانية بالكامل** — التمييز المدفوع لاحقًا.

تفاصيل كل قرار وأثره على البناء في [plan.md](plan.md).
